## 2. 高風險操作

原則：未經授權不得執行寄信、發文、付款、刪除資料、變更成績、核定公文等有實質影響的行為；高風險操作須設人工確認、權限分級及完整紀錄。

| 項目 | 狀態 | 做法與證據 |
| --- | --- | --- |
| 送出邀請需人工確認 | 已做 | 協調器只能彙整名單；使用者勾選並確認後才送出。寫入工具沒有確認許可就被拒絕。評測 D07、測試「寫入工具需人工確認」 |
| 只能邀請經檢核的對象 | 已做 | 評測 D06 |
| 指導關係需教師同意 | 已做 | 只有受邀者能回覆；名額滿了不能再接受 |
| 系統不變更成績、不刪除他人資料 | 已做 | 沒有這類工具；相關請求在輸入防護就被攔截。評測 D02 |
| 實際寄信或通知 | 不適用 | 原型只寫入資料庫，沒有對外寄送 |
| 完整紀錄 | 已做 | 每次決策、工具調用、閘門、確認、模型升級都有事件；登入、確認、邀請、驗證、MCP 工具呼叫與權杖核發另有稽核紀錄 |
| 外部 AI 不能執行寫入 | 已做 | MCP 只開放唯讀工具，邀請仍須本人在系統內確認 |

## 7. 第二次獨立審查紀錄（2026-11-12，MCP、多模型、資料品質）

新增 MCP 伺服器、模型路由與資料品質模組後，再請一位不帶開發者結論的審查者針對這些部分逐項找反例。結果：沒有重大（CRITICAL）問題，高 1 項、中 9 項、低 8 組，都附了重現步驟。**全部已修正**，回歸測試在 `test/review2.test.js`（18 項）。

| 等級 | 問題 | 處理 |
| --- | --- | --- |
| 高 | 自製 JSON Schema 驗證器在超過項數上限後仍逐一比對唯一性（二次方時間）；一把 MCP 權杖送 3 萬多項的陣列就能拖慢整台伺服器 | 超過上限即判定不合格、不再逐項檢查；唯一性改為線性時間；MCP 請求上限降到 64 KB |
| 中 | MCP 連線階段表全域共用，滿了就淘汰最早建立的，別人的權杖可以把你正在用的連線擠掉 | 每把權杖最多 5 個連線階段、只淘汰自己最久沒用的；全部滿了拒絕新連線（503） |
| 中 | stdio 用 readline 切行，含 U+2028／U+2029 的合法訊息會被切斷而沒有回應 | 改為只依 `\n` 切行（與官方 SDK 相同） |
| 中 | 個資遮蔽漏掉全形數字、括號區碼、國碼、句點分隔、小寫身分證字號、新式統一證號 | 先轉半形再比對；補齊格式；加上居留證號 |
| 中 | 路由設定檔把端點宣告為地端，但網址改到雲端時完全不遮蔽 | 端點位置一律依網址判定；校內主機名稱需明確列在 `FOMO_TRUSTED_LOCAL_HOSTS` |
| 中 | 課綱的可疑內容檢查在去除標籤之後才做，被跳脫的腳本標籤永遠抓不到；清理後變空白的週次仍算數 | 在解碼後、去標籤前檢查；空白週次不計 |
| 中 | 舊版資料庫的證據沒有品質欄位，被當成品質合格 | 沒有品質評估一律不算已驗證；加入資料版本，舊資料庫啟動時自動重新盤點 |
| 中 | 資料契約從未經過關鍵字檢查，寫了不支援的關鍵字會被默默略過 | 資料品質檢核前先檢查契約，並檢查關鍵字值的型別 |
| 中 | 別名比對的新邊界規則把「1.Python」這類編號清單也擋掉 | 只排除「英文字母＋.」之後的情況（Node.js 仍排除） |
| 中 | 可疑內容偵測把資安、AI 課程的主題詞（System Prompt、Jailbreak、onclick=）也當成攻擊，整門課被降級 | 外部文件只抓對模型下指令的文字與真的 HTML 標籤 |
| 低 | 萃取評測的 `--llm` 讀不到 `.env`；評比工具沒算到模型鏈中途被丟棄的輸出、錄到的是資料庫原文而非清理後的課綱 | 已修正；萃取與評比都改用與正式流程相同的課綱來源（數字不變） |
| 低 | 模型把人員代號改寫成變體（全形數字、方括號）時會直接顯示；任務辨識與下一步選擇沒有代號化目標中的人名 | 變體一律改用範本；兩個用途都代號化；資料契約要求姓名至少 2 個字 |
| 低 | MCP 使用者看得到資料品質樣本中其他學生的證據標題與修課紀錄 | 可能提到個人的規則，非管理者只看得到數量 |
| 低 | 壞掉的百分比編碼回內部錯誤；`application/jsonp` 被當成 JSON；協定版本標頭沒比對協商結果；只有空白的搜尋字串回傳全部技能；`__proto__` 路由名稱報錯不友善；課綱庫外課程沒有課名也能過閘門；NaN 與含空白的網址與 AJV 判定不一致 | 全部修正 |

審查同時確認了這些性質沒有找到反例：MCP 工具唯讀（無法送出邀請）、輸出不含他人的精確分數、帳號與權杖綁定、HTTP 端點預設關閉與各項標頭檢查、協定層的錯誤分類、stdio 只輸出協定訊息、路由器的成本累計與金鑰不外洩、說明文字的代號化與事實檢核、資料閘門與課綱降級、沒有 import 循環。
