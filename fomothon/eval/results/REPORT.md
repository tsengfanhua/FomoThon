## 9. 已知限制

- 案例與相關名單由團隊依合成資料自行設計與標註，不是獨立第三方的評測；成功率反映的是「系統是否符合設計要求」，不代表真實場域成效。

- LLM 模式（任務辨識、課綱語意萃取、下一步選擇、說明潤飾）尚未以真實模型端點評測；執行 `npm run eval -- --llm` 可取得該模式的成功率、延遲與成本。
- 場域驗證（真實學生與教師試用、前後比較）不在本報告範圍內。
